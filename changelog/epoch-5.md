# Epoch 5 — Canonical Boards

Registers the epoch-owned category catalog and the five Phase-0 board definitions. Existing
production rates, costs, caps, and pacing are unchanged. Runs pin their category definitions with
the rest of their catalog artifacts, so later category changes cannot reclassify historical runs.

The Phase-0 completion set is intentionally empty: 100% is currently the all-gates category.
Ethical% reserves the `darkpattern.*` and `externality.*` fact namespaces; no Phase-0 action emits
either yet. Valuation ranks exact terminal lifetime value and is available to pre-timer runs.
