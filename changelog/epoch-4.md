# Balance Epoch 4 — Guild Runtime

Activates the published Guild runtime constants: 250,000 tier-progress XP per active founder for
full Guild Health and one deterministic clearing boundary every 300,000 milliseconds. The
production catalog declares `guild.stock_consumption` in the existing faction multiplier slot;
its Phase-0 rate remains exactly zero, so this epoch changes ownership and replay identity without
silently changing production output.

Cap migration: no hardcap is lowered. Existing runs remain playable under their pinned identity;
new runs use the Epoch-4 artifact bundle.
