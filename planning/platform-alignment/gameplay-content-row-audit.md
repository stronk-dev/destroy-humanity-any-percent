# Deploy-current gameplay-content row audit

Coordinate: product tree `190a4fa`; 2026-08-21. This audit attaches loader, runtime producer,
mounted consumer, current reachability, executable witness, limitation, verdict, and authority route
to all 579 structural units in `gameplay-content-row-structure.tsv`.

## Result

| Verdict | Units | What it means at the audited coordinate |
|---|---:|---|
| `proven_mounted_effect` | 0 | No exact current row has a row-discriminating integrated player-effect witness. |
| `proven_mounted_presentation` | 0 | No exact current row has a row-discriminating mounted presentation/selection witness. |
| `partial_mounted` | 173 | Real row and mounted consumer exist, but only separate server/component evidence or an incomplete default workflow exists. |
| `backend_active` | 180 | Current row reaches a backend transition/projection with no intended mounted player workflow. |
| `backend_registered_dormant` | 141 | Row loads, but current triggers/content/default workflow cannot activate it. |
| `measurement_only` | 55 | Relevance policy configures developer measurement, not gameplay; the complete hosted run is invalid. |
| `zero_or_empty_placeholder` | 21 | Empty or exact-zero current payload contributes no represented relationship/effect. |
| `contradicted` | 9 | Exact current row conflicts binding intent/design or another current governed artifact. |
| `uncomposed` / `blocked` | 0 | All 19 files load; no row needed these verdicts after factual reachability was established. |

Zero proven mounted rows does **not** mean the UI renders no current data. It means the available
proof stops short of an exact row's default producer-to-consumer effect. The real composed browser
test ends at Desk bootstrap without performing gameplay. Browser screen tests inject fabricated
snapshots/events, while server tests exercise current rows without the production browser. Those
separate witnesses support `partial_mounted`, not integration.

The 173 partial-mounted units are 154 economy units, seven curriculum units, seven Prestige units,
three route units, and two category units. All other deploy-current content is backend, dormant,
measurement-only, empty/zero, or contradicted.

## Dormant and empty content

The 141 registered-but-dormant units are:

- 41 meter units: Doom has no deploy-current `externality.emitted` producer; nine other meters have
  empty inputs and begin at their decay target;
- 37 later-tier gate/route units, unreachable from the current T0–T1 game;
- all 23 pet policy/action/behavior units because no current producer acquires a companion;
- 19 later-tier or multi-run achievement/condition/proof units;
- nine Tier-2/Tier-3 economy/resource/progress units;
- eight later-tier Prestige spawn thresholds; and
- four lower Soul bands plus the ending policy because deploy-current Soul debit sources are empty.

All 39 structural empty collections remain accounted for. Nineteen Relevance grouping empties are
measurement-only rather than gameplay placeholders. The other 20 empty collections plus the exact
zero guild consumption-bonus scalar produce the 21 `zero_or_empty_placeholder` rows: nine meter
input sets, four faction modifier-slot sets, three early-gate route sets, and one each for the final
generator ladder, category completion facts, Commons source weights, Soul debit sources, and guild
consumption bonus.

These are reachability statements, not automatic removal recommendations. Several empties may be
intentional current-scope boundaries; their owner must say so under the routed content/RFC work.

## Nine exact contradictions

1. `upgrade.reply_all_macro` and its exact multiplier effect are mounted/backend-real but do not
   automate Tier-0 work as binding Tier-1 intent states. A still-manual multiplier is not
   automation. This is RP-110.
2. Fiscal credit policy and the Beige Tower level row emit `cap.fiscal_credit` and
   `cap.fiscal_level.beige_tower`, absent from the governed application Copy catalog.
3. Opportunity `active.lucky` and combo policy emit `cap.cash` and `cap.active_combo`, also absent
   from the catalog. These four cross-artifact defects remain RP-109.
4. All three positive Soul recovery activity rows are default-unreachable because `debit_sources`
   is empty. They also sit inside RP-017's binding design contradiction: one paragraph forbids
   restorative hobbies while later text grants restorative Go/Arcade behavior.

The audit records these contradictions; it does not edit owner-authored intent or content.

## Controls and limits

The structural extractor reproduced all 579 payload identities byte-for-byte. The verdict validator
rejects dropped/duplicate units, a backend row relabeled as mounted, an empty row relabeled active,
and a missing authority route. Every unit retains one exact route.

This is repository evidence, not a balance-quality or participant-fun study. `backend_active` does
not mean balanced, discoverable, accessible, or release-ready. `partial_mounted` does not prove the
first hour. `measurement_only` does not rehabilitate the invalid hosted Relevance result. Product,
content, copy, design/RFC, and canonical product documentation remain unchanged by this wave.
