Declared readings before any code:
- **Version numbering is landing-order.** The RFC's "Founder v22" is next-free, which at landing is
  **v25**. The `server_garden` artifact therefore sits on the scalar Founder chain above
  `cosmetics`: garden pinned ⟹ cosmetics pinned ⟹ … ⟹ `minigame_api`.
- **Clout:** under Clout v1's OD-1 option A, the garden carries no Clout payload.
- **Host generator (OD-14):** Tier 2 exists only as fixture candidates. The fixture host is the
  existing Fiscal `generator_level_rows` row `generator.beige_tower`. SG12 explicitly allows this
  ("the host is the fixture generator row, until Tier-2 content supplies the real one").
- **Fiscal fixture:** the fixture Fiscal artifact gains `{unlock_id: "minigame.server_garden",
  cost: 3}` in a garden fixture bundle only. Production Fiscal bytes are untouched.
- **API C2:** the read endpoint is a new operation (allowed widening). Garden commands are Founder
  intents on `/api/v1/intents`, which is not in the generated registry. Nothing widens an existing
  v1 union; if anything would, it is recorded here as blocked on the owner ruling.
- **Kernel protocol:** each commit touching a guarded path bumps `kernel/VERSION` in the same
  commit. New dirs `server/garden/` and `client/src/garden/` are registered as guarded.

## 2026-09-25 — G1: loader, state, engine, commands, and the Go/TS corpus (Claude)

**Implemented by:** Claude. Awaiting Codex's designated review. Kernel bumped 0.3.130 → 0.3.131 in
the same commit. `server/garden/` and `client/src/garden/` are now registered as guarded.

- **`server/garden`:**
  - `catalog.go`: SG1, every rule.
  - `state.go`: the SG2 codec rules.
  - `engine.go`: the SG3 advance and SG4 tick. Draws come from
    `Substream(Substream(salt,"garden.founder.v1").Next() ^ s, "garden.tick.v1")`, keyed by the
    absolute tick `s`. The engine has the fixed-point skip, visible catch-up forfeiture, and the
    clock-regression no-op.
  - `commands.go`: the SG5 pure commands with every closed detail, and SG6's Founder-side harvest.
    Units are `floor(units × frozen_effect / 1e6)`, seeds are collected, and `harvest_hash` is
    SHA-256 over canonical sorted-key JSON.
- **`client/src/garden`:** the byte-twin. Objects are built in Go field order, and the one product
  that can exceed 2^53 (`harvest_units × effect_ppm`, up to 1e16) uses BigInt.
- **Fixtures:**
  - `balance/testdata/server-garden/fixture-v1.json` is exactly SG12.
  - `fiscal-fixture-v1.json` is the production Fiscal artifact plus `minigame.server_garden` (cost 3).
  - `testdata/garden/catalog-fixtures-v1.json` holds 47 rejecting cases shared by both runtimes.
  - `testdata/garden/engine-corpus-v1.json` is generated by the real Go engine (`make garden-corpus`)
    and checked by `make garden-corpus-check`.
- **Copy:** `copy/catalog/garden-candidate.json` has every SG11 key. The text is candidate text;
  species names say `PENDING OWNER NAME`, descriptions say `PENDING OWNER COPY`, and Chaos Monkey's
  tooltip says `PENDING OWNER VALUE`.

Evidence, cold (`-count=1`):
- `go test ./garden` passes.
- `vitest test/garden-engine.test.ts` passes 6/6.
- `make garden-corpus-check` passes.
- **AC1:** all 47 cases reject in both runtimes, and the production Fiscal artifact rejects the
  fixture garden (rule 10).
- **Severing (Go):**
  - Reachability off → `unreachable_species` loads (red).
  - Satisfiability off → `unsatisfiable_recipe` loads (red).
  - A 4-neighbour census → the diagonal-cross corpus vector goes red. This is AC4's named failing
    case.
  - Draws keyed by the relative step instead of the absolute tick → the partition test goes red.
  - A silently truncating catch-up → the catch-up vector goes red (AC5).
  - A stored-cursor PRNG variant diverges under a split; this is AC3's named failing case, kept
    in-suite as `TestGardenCursorPRNGBreaksPartition`.
- **Severing (TS):** a 4-neighbour census, reachability off, and unkeyed tick draws each turn one
  test red.
- **Finding (rule 8):** SG1 rule 8's evaluation budget can never trip within rule 3's domains. The
  worst case is ⌈604,800,000 / 60,000⌉ × 36 = 362,880, well under 2,000,000. No artifact fixture
  can reach it, so `TestGardenBudgetRuleRejects` proves the check directly on an out-of-domain
  catalog. The rule is redundant as specified; this is logged, not a defect.
